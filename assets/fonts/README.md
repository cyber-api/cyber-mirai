# Bundled fonts

These fonts are committed so command startup never depends on a third-party raw
URL (the old `catalizcs/storage-data` URLs return 404).

- `regular-font.ttf` — Roboto Regular
- `bold-font.ttf` — Roboto Bold

Source: https://github.com/googlefonts/roboto
License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)

`Rank.js` registers both files under the family name `Manrope`, preserving the
font names used by the original rank card code.
